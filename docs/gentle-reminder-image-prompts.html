Sixteen reminders, nine pictures

Every Gentle Reminder used to show the same illustration — the woman breathing among the trees — because the card had one hardcoded image. Below is the prompt behind each replacement, kept for re-rendering one or writing another. The style block is folded into every prompt, so you can copy a single card and paste it straight into an image model.

Live on antisocial.co.in

  • Production has sixteen reminders, not eight. The first version of this sheet counted the local dev Mongo that backend/.env points at; Atlas holds twice as many. Half of all live reminders were falling through to the fallback until that was fixed — count against the deployed API, never the local database.
  • Thirteen of the sixteen now resolve to art, from nine images. Five reminders share a picture with the one that says the same thing in other words: a jaw is a jaw.
  • Renders live at frontend/assets/art/reminder-*.jpg — 1600×1365, quality 88, progressive, about 160 KB each. The 48 MB originals stay in Curious app/Img/, outside the repo.
  • Gemini's sparkle watermark sat at x 2109–2208 in every render and is cropped out — which is why they're 1.17 rather than 4:3.

The style block

Here on its own in case you want to prompt something that isn't on this list. Each card button below copies this block plus that card's subject. 

Flat-shaded editorial vector illustration with soft matte gradients and a fine paper grain — the calm, modern picture-book style used by wellness and meditation apps.
Warm muted earthy palette only: parchment cream #EFECE5, off-white #F7F5F0, terracotta rust #C27B5E, muted sage #8BA087, deep forest green #3F5B4A, warm ochre #D9AD6A, soft charcoal #2D2C2A.
Gentle tonal shading inside each shape, soft edges, no hard outlines, no glossy highlights, no drop shadows, no harsh contrast, no neon.
Layered depth: foreground leaves or objects framing the edges, a soft misty middle distance, a pale cream sky.
Calm, unhurried, contemplative mood. Generous quiet space around the subject.
No text, no letters, no numbers, no words, no logos, no phones, no screens, no user-interface elements, no watermarks.
Wide 4:3 landscape composition, 1600 x 1200 pixels, subject centred with headroom so the image survives a centre crop.

Written for 4:3, which is what the first batch was generated at. The shipped files are cropped to 1.17 afterwards to lose the watermark — if you'd rather skip that step, ask for 1400 × 1200 and check where the sparkle lands.

Keep one woman across the set

Five of the nine pictures have a person in them. Describing the same person every time is what makes separate renders read as one set instead of five strangers. That description is already inside each figure prompt below — it's the woman from the original breathing image. The still lifes don't take it, and neither does the overhead feet shot, where nothing above the shins is in frame. 

The same woman throughout: long dark wavy hair, warm mid-tone skin, a terracotta rust cardigan over a cream top, soft calm features, eyes closed or lowered, no jewellery, no makeup detail.

If you re-render one

What the first batch taught, so a replacement drops in cleanly.

  1. The frame is portrait, not landscape. Measured in the running app at 348 × 400 pt on a normal phone — cards.artFill is flex:1, minHeight:240, maxHeight:400. With resizeMode="cover" a 4:3 render loses 35% of its width; the shipped 1.17 crop loses 26%. Keep the subject centred and away from the sides.
  2. It goes landscape on short screens. At a 640 pt viewport the same frame measured 348 × 262 and showed 99% of the width. Anything parked in a corner is hidden on one device and plainly visible on the other, so check both.
  3. Crop the watermark before shipping. Gemini's sparkle lands at x 2109–2208, y 1503–1600 in the 2400 × 1792 output. Crop to x < 2100 and resize to 1600 wide.
  4. Use an anchored crop tool. sips -c crops centred and ignores --cropOffset, which quietly keeps the watermark while looking like it worked. PIL's im.crop() is exact.
  5. Re-prompt "no text" from the front. If lettering shows up, move the no-text clause to the first sentence rather than adding it again at the end.

How a new one gets wired

For a ninth reminder, or a replacement under a different filename.

  • Metro needs literal require paths, so AlmostNothingCard.tsx holds a static ART map and an artFor() lookup rather than building a path at runtime.
  • The key is the reminder's opening line, lowercased and whitespace-normalised — not the content id, because the populate scripts mint fresh UUIDs on every repopulate while the text stays put.
  • An unmapped line falls back to pause-woman.png, so a reminder written into the database before its art exists renders something rather than an empty frame.
